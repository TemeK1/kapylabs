# Kapy Labs

Kapy Labs is an independent software studio from Finland.

We make thoughtful, useful apps with a calm approach to design. We care about clarity, privacy and the small details that make software pleasant to use.

Our projects include RIVI, a focused reading app designed to help readers keep their place and become immersed in the story.
