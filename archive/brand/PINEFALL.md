# Pinefall Labs logo

An original cone mark, matching the website header and favicon.

- `pinefall-mark-{256,512,1024}.png`: warm cone mark, transparent square canvas.
- `pinefall-logo.png`: cone and Pinefall Labs wordmark, transparent 1160 × 320 canvas.
- `-light` variants: off-white artwork for dark app backgrounds.
- `-dark` variants: forest-coloured artwork for light app backgrounds.
- SVG variants are editable source assets and can scale to any size.

Use the square mark for small studio credits or badges and the horizontal logo where the full studio name should appear. PNGs have transparent backgrounds; these are studio branding assets, not replacements for RIVI's own app icon.

Regenerate with `node scripts/export-logo.cjs` with Sharp installed or `PINEFALL_SHARP_PATH` pointing to the bundled Sharp package.
